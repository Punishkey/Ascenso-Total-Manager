# Ascenso Total Mánager

#### Juego de Mánager de Fútbol en Discord (bot)



Este proyecto es un bot de gestión de fútbol (Fútbol Mánager) diseñado para Discord, desarrollado desde cero con Python y discord.py. El objetivo es proporcionar una experiencia de simulación de gestión deportiva competitiva dentro de servidores de Discord, permitiendo a los usuarios fundar sus propios clubes, gestionar plantillas generadas aleatoriamente y competir en un entorno persistente basado en una base de datos SQLite. 



A diferencia de otros bots, este sistema ha sido creado de forma independiente, sin depender de APIs externas de fútbol, lo que garantiza total libertad creativa y cumplimiento legal al no utilizar marcas ni imágenes registradas.





##### **Características Principales**



**Gestión de Clubes:** Los usuarios pueden fundar su propio club utilizando comandos sencillos.  Simulación desde Cero: Sistema propio de generación aleatoria de jugadores y estadísticas.  



**Arquitectura Modular:** Estructura escalable basada en Cogs de discord.py para facilitar el mantenimiento y la expansión de funcionalidades.  



**Persistencia de Datos:** Utiliza SQLite para asegurar que la información de los clubes y plantillas se mantenga activa incluso tras reinicios.
